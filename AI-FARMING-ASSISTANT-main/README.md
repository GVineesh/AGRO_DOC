## 📖 Overview

AI Farming Assistant is an intelligent agriculture platform designed to assist farmers with data-driven farming decisions through Artificial Intelligence and Machine Learning.

The application combines modern web technologies with AI models to provide crop recommendations, plant disease identification, multilingual interaction, and smart agricultural guidance. It focuses on improving productivity, accessibility, and decision-making for farmers while demonstrating practical AI application development.

This project showcases full-stack software engineering, AI integration, computer vision, and responsive user interface design.

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/SANJAYDURAI77/AI-FARMING-ASSISTANT.git
```

### Navigate to Project

```bash
cd AI-FARMING-ASSISTANT
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
